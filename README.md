# 💰 Finance Dashboard UI  
### 🚀 Zorvyn Frontend Assessment Submission
## 🌐 Live Demo

🔗 https://finance-dashboard-eta-nine.vercel.app/

---

## 📌 Overview

This project was built as part of the **Zorvyn Frontend Assessment**.

The goal of this assignment was to design and develop a clean, interactive, and user-friendly finance dashboard that allows users to track and understand their financial activity.

The implementation focuses on frontend architecture, UI/UX design, and state management without relying on backend services.

---

## 🎯 Approach

While working on this assessment, I focused on:

- Designing a clean and intuitive user interface
- Structuring components in a modular and reusable way
- Managing application state efficiently using Context API
- Simulating real-world features like role-based access
- Enhancing UX with modern design patterns and interactions

---

## 🚀 Features Implemented

### 1. Dashboard Overview
- Summary cards:
  - Total Balance
  - Total Income
  - Total Expenses
- Visualizations:
  - Line chart (transaction trend over time)
  - Pie chart (spending breakdown by category)

---

### 2. Transactions Section
- Displays:
  - Date
  - Amount
  - Category
  - Type (Income / Expense)

- Functionalities:
  - Search/filter by category
  - Add new transactions (Admin only)
  - Edit existing transactions (Admin only)
  - Delete transactions (Admin only)

---

### 3. Role-Based UI (Simulated)
- Viewer:
  - Read-only access
- Admin:
  - Can add, edit, and delete transactions

- Role switching implemented via dropdown for demonstration

---

### 4. Insights Section
Provides useful insights:
- Highest spending category
- Total expense amount
- Average expense per transaction

---

### 5. State Management
- Implemented using **React Context API**
- Handles:
  - Transactions data
  - Role state
  - Filters
- Keeps logic centralized and scalable

---

### 6. Data Persistence
- Uses **LocalStorage**
- Ensures data remains after page refresh

---

### 7. UI & UX Enhancements
- Apple-inspired clean design 🍎
- Responsive layout across devices
- Dark mode toggle 🌙
- Smooth hover effects and transitions
- Clear visual hierarchy
- Graceful handling of empty states

---

## 🛠️ Tech Stack

- **React (Vite)**
- **Tailwind CSS**
- **Recharts**
- **Context API**
- **LocalStorage**

---
